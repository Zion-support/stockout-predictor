# Stockout Predictor

**Zion Stockout Predictor** — SKU/location stockout risk scores and replenishment alerts before shelves go empty.

> Part of the **Zion AI App Network** — see [ZION_APP_NETWORK.md](./ZION_APP_NETWORK.md) for the full mesh of interlinked apps.

Live app: https://ziontechgroup.com/stockout-predictor/

## ✨ Features
- **SKU/location risk scores** — daily stockout probability per SKU per store/warehouse.
- **Demand-sensing forecasts** — blends seasonality, promos, weather and local events.
- **Replenishment alerts** — prioritized reorder recommendations with lead-time awareness.
- **Lost-sales estimator** — quantifies revenue lost to each stockout.
- **Safety-stock optimizer** — balances availability vs. carrying cost per item.
